### Primeiro Projeto - Servidor residancial

[Site Guzzy](https://guzzy.com.br)
Nesse projeto, criei um servidor caseiro instalando o Ubuntu Server 22.04 em uma máquina que estava parada em casa. Esse servidor tem um túnel conectado ao Cloudflare para tornar acessível externamente em formato de subdomínios os serviços que rodam nessa máquina pois meu provedor de internet trabalha com o sistema de CGNAT, impossibilitanto a utilização de portas.
Como sou um amante de filmes, criei meu próprio servidor de mídias, utilizando o Jellyfin para acessar de qualquer lugar meu filmes e séris preferidas. Nele também rodam serviços de torrent, cloud para armazenamento de arquivos e fotos, monitores de gerenciamento da maquina, automação como home assistant e serviços de games, como um emulador que é acessível via browser pelo subdomínio [Rom.guzzy.com.br](https://rom.guzzy.com.br)
Como todos os serviços possuem esse subdomínio, estou criando no wordpress uma página que torna mais fácil minha apresentação/portifólio e com acesso aos links de forma mais rápida.
